# Maze Runner with AI-Controlled Enemy

A maze game where the player collects coins and reaches the goal while avoiding an AI-controlled enemy. The enemy uses BFS pathfinding to find and follow the player through the maze.

## Features

- Maze-based player movement
- Collision detection with walls
- AI-controlled enemy
- BFS pathfinding
- Coin collection
- Score system
- Timer
- Win and game-over screens

## Technologies Used

- Python
- Pygame
- BFS (Breadth-First Search)
- GitHub
